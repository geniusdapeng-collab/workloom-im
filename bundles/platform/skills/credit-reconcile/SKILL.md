# 积分对账

## 一、何时调用
- 每日 02:00 例行对账；billing 意图查账作答时；异常扣费检测命中时；月度账单生成时。

## 二、执行步骤
1. **三方核对**：实时余额投影 vs 日结投影（日初+入账-出账=日终）vs 事件重放——事件库为唯一基准；
2. **差异处置**：差异≠0 → 生成核查工单（必人审 R-PL1）+ 冻结该租户自动赠款动作，直到差异清零；
3. **异常检测**：单租户扣费速率超基线 3σ / 单笔超阈值 → credit.anomaly 事件必人审；
4. **查账作答**：billing 意图命中时直接调账本投影——哪个员工、什么任务、什么模型档位、扣了多少，30 秒可答；争议升级人工，携带账本投影介入；
5. **月度账单**：消耗分布/任务构成/同比环比，推送客户管理员。

## 三、边界与围栏
- 退款/手动赠积分走 R-PL1 人审；涉及钱的动作永不全自动；
- 钱的路径不走缓存：扣费判定读强一致投影，监控展示读最终一致投影；
- 账本只增不改；纠错走逆向补偿事件。

## 四、与其他技能的协作
- 上游：模型路由扣费事件流；下游：billing-officer（账单）、strategy-forge（billing_hint 加油包时机提案）。
