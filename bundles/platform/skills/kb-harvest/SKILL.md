# 知识沉淀

## 一、何时调用
- 工单关单后；新版本/新能力上线时；故障或投诉复盘完成后。

## 二、输入契约
- 已解决工单（对话+处置记录）；版本发布说明；复盘报告。

## 三、执行步骤
1. **关单沉淀**：从已解决工单提取"可复用问答"候选（去个资、去租户标识、提炼通用问答）；
2. **发布沉淀**：版本发布/新能力上线时自动生成对应知识条目（功能说明+用法+注意事项+生效版本）；
3. **复盘沉淀**：故障复盘、投诉复盘后产出预案类知识（如《队列积压自查指引》）；
4. **版本对齐**：每条知识绑定适用版本范围——客户按其实例版本命中对应答案；
5. **草案 → 发布**：草案组织后提交 R-PL8 人审发布；每条知识记录命中次数与解决率。

## 四、知识内容范围
产品功能说明 / 常见问题 FAQ / 故障自查预案 / 政策条款（SLA/隐私/安全）/ 定价与积分规则 / 版本变更日志 / 服务话术规范 / 已知问题清单。

## 五、边界与围栏
- 知识发布走 R-PL8 人审（对外口径统一闸门）；
- 禁止删除知识，只可下线/归档；对外答案必须可溯源到知识条目。

## 六、与其他技能的协作
- 上游：ticket-ledger（关单）、incident-playbook（复盘）；下游：kb-fresh（保鲜巡检）、fae-chief（作答弹药）。
