# 故障应急 Playbook

## 一、何时调用
- 巡检检项异常（事件库积压/队列深度/模型路由延迟与失败率/存储水位/租户实例在线率）；
- 客户 bug_report 故障直通时；僵尸 run / 漏触发 / 技能零调用检出时。

## 二、分级与路由
| 级别 | 定义 | 触达 |
|---|---|---|
| P0 | 平台级故障/兜底链耗尽/断链 | 电话+短信+WS（5min 未确认升级二线） |
| P1 | 单域异常/>10 租户同症状 | WS + 移动端推送 |
| P2 | 单租户/容量类 | 清晨决策包 |

同源告警聚合为一条事件（防告警风暴）；所有告警自动生成工单，处理全程记账。

## 三、预置 playbook（低危自动执行，高危人审）
1. **模型路由切备用供应商**：失败率 >50%/1min → 熔断 30s → 半开试探 → 走降级链；全链熔断 → 排队 + P0；
2. **队列限流**：单租户速率超配额 10 倍 → 切入"慢车道"独立低优先级队列（noisy neighbor 防护）；
3. **实例重启**：僵尸 run 连续 3 次 → 熔断该 run → P1 + 需介入工单（附完整事件时间线）；
4. **漏触发对账**：cron 应触发 vs 实际触发独立重算，漏触发 >5min 即 P1。

## 四、故障通报与复盘
- 影响客户面的故障：受影响租户名单核对 + 通报草拟 → R-PL7 人审 → 逐户送达留痕；
- 复盘产出预案类知识条目回流知识库（告警闭环回流）。

## 五、边界与围栏
- 高危处置人审；低危自动执行全程记账；禁止静默关闭故障。

## 六、与其他技能的协作
- 上游：巡检检项/客户报障；下游：kb-harvest（复盘沉淀）、rollout-watch（版本关联）。
