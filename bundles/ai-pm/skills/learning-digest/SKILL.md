# 学习周刊与固化建议

## 一、何时调用
- 每周固定窗口（默认周日夜班）聚合产出；
- 重大行业事件后加刊。

## 二、输入契约
- 一周四路信号（industry-radar / model-scout / competitor-scan / review-miner 产出）；
- 内部样本：审批驳回记录（按 feedback-enums v2 分类统计）、eval 退化记录、高频重复动作（意识系统产出）。

## 三、执行步骤
1. 聚合一周信号与内部样本，去重、按主题聚类；
2. 按**三层信息食谱**组织：论文与研究动态 / 工程实践 / 产品与商业动态；
3. 每条附"与我们的产品有什么关系"研判（影响哪个功能、要不要行动、谁该看）——不是资讯搬运，是带观点的内参；
4. 产出**固化建议**：高频重复动作 → "固化为技能"建议；高频驳回模式 → "规则加严 / eval 增补"建议；每条附证据链（重复次数/样本/预期收益）；
5. 周刊发布走 R-PM1 人审；固化建议单独成卡，**人批准才执行**。

## 四、边界与围栏
- 权限面：周刊与建议写库（R-PM1 人审）；绝不自动执行固化。
- 每条内容附来源与置信度；C 级信息只作线索不作决策依据。

## 五、与其他技能的协作
- 上游：四路信号技能、审批中心、意识系统；
- 下游：kb-fresh（学习成果入库）、forge（人批准后的技能固化执行）、fence patch（人批准后的规则调整）。
